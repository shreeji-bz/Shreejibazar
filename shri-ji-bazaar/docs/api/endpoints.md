# API Endpoints

## Mobile Endpoints
- GET /api/system/status
- GET /api/games/popular
- GET /api/games/recent
- GET /api/games/:id
- GET /api/results/latest
- GET /api/results/game/:gameId
- GET /api/banners
- GET /api/settings

- POST /api/auth/login
- POST /api/auth/logout
